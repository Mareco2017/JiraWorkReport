# 项目文档索引

本仓库提供 JIRA 工时填报桌面应用的源码、测试和打包脚本。

## 使用与开发

- [项目说明与运行命令](../README.md)
- [应用入口](../app/main.js)：创建桌面窗口、连接本地存储与业务服务。
- [个人待办业务](../app/todos.js)：管理本机待办、分组、状态和评论，独立于 JIRA 工作区。
- [个人待办界面](../app/ui/todo/view.js)：提供列表、日历、抽屉和本机查询偏好记忆，应用默认进入此页。
- [个人待办测试](../tests/todos.test.js)：验证独立保存、完整业务操作及失败恢复；[真实界面测试](../tests/todo-ui.test.js)验证保存与跨进程重开。
- [工作台共享侧栏](../app/ui/sidebar.css)：五个菜单统一沿用工时填报样式；[侧栏真实界面回归](../tests/sidebar-ui.test.js)验证菜单切换、原节点保持和连接摘要增量更新。
- [工作台业务入口](../app/service.js)：处理连接、草稿、月度工单绑定和提交动作。
- [JIRA 与 Tempo 接口](../app/jira.js)：封装工单和工时读写。
- [提交协调](../app/submission.js)：处理逐条提交、结果核对、失败重试和历史记录。
- [周笔记读取](../app/week-notes.js)：按用户选择的文件夹读取工时笔记。
- [Agent 接入](../app/agent.js)：调用 CLI 生成工时类型及子任务建议。
- [自动测试](../tests/)：使用虚构账号、工单和受控接口验证业务行为。
- [打包脚本](../scripts/package.mjs)：生成 macOS 和 Windows 应用及 ZIP。
- [手动 Release 构建](../.github/workflows/release.yml)：手动指定源码提交和已有 Release 草稿，执行测试、生成三平台 ZIP，核对源码、架构和公开范围后上传附件；核对完成后再正式发布。

## 公开范围

原始需求、内部设计文档、真实联调记录和验收截图保留在维护者本机，未纳入公开仓库。仓库不包含 JIRA 凭据、模型服务密钥、个人笔记、已填报记录、开发依赖目录。应用及 ZIP 由打包命令生成，保留在本机 `dist/` 目录，并由 Git 忽略。

应用当前适配 JIRA Server 与 Tempo 的特定工单类型、自定义字段和工时规则。接入其他站点前，需要核对该站点的字段与权限；具体配置见项目说明。
